# IntelliCart
IntelliCart is a GenAI-powered smart supermarket trolley that transforms physical shopping. Using a zero-install mobile web bridge &amp; Supabase Realtime, shoppers beam YouTube recipe links from their phones to the trolley tablet. Groq (Qwen 3.8-27b) instantly extracts ingredients and maps them to store aisles in real time. 🛒✨
